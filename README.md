### 스타일 레이어

```

        ├ styles.css   홈
        └ work.css     상세 4종
```

상세 페이지는 `work.css`에서 `--shell: 1100px` 로 본문 폭을 좁힙니다. 홈은 기본값 1200px입니다.

`main.js` 는 5개 페이지가 함께 씁니다. 상세 페이지에는 내비게이션 링크와 모바일 메뉴가 없지만, 해당 엘리먼트가 없으면 그 기능은 그냥 동작하지 않도록 되어 있어 별도 분기가 필요 없습니다.

## 출처

Claude Design 프로젝트의 `Portfolio.dc.html` 와 `Work 01~04` 4종을 구현한 결과물입니다. 캔버스 전용 문법(`<x-dc>`, `{{바인딩}}`, `<sc-if>`, `DCLogic`, `support.js` 런타임)은 모두 표준 HTML/CSS/JS로 옮겼습니다.

- `style-hover` 속성 → CSS `:hover`
- `<sc-if>` 조건부 렌더링 → `hidden` 속성 토글
- `{{email}}` / `{{github}}` 프롭 → 리터럴 값
- `.dc.html` 파일 간 링크 → 실제 파일명(`work-01-inova.html` 등)

### 원본에서 고친 것 — 스크롤 스파이

원본은 `IntersectionObserver` 의 **교차 전환**이 일어날 때만 활성 링크를 설정했습니다. 이 방식은 앵커로 페이지에 바로 진입하는 경우(`index.html#work` — 상세 페이지의 "← 전체 프로젝트"가 전부 이 경로) 보고할 전환이 없어서 하이라이트가 엉뚱한 곳에 남습니다.

같은 밴드(뷰포트의 35%~45% 구간)를 쓰되, 스크롤마다 좌표로 직접 계산하도록 바꿨습니다. 밴드에 걸친 섹션 중 **마지막** 것을 고릅니다 — 두 섹션이 동시에 걸칠 때 사용자가 진입하고 있는 쪽은 뒤쪽이기 때문입니다.

## 반응형 기준

데스크톱 1440px, 모바일 390px에서 확인합니다.

- 상세 페이지 히어로는 900px 이하에서 1열로 접힙니다.
- 640px 이하에서 상단 내비게이션은 `← 전체 프로젝트` 와 현재 위치(`04 / 04`)만 남기고, 다음 프로젝트 링크는 페이지 하단 페이저에만 둡니다.
- 640px 이하에서 2열 표는 각 행이 세로 카드로 바뀝니다. 표의 `<td>` 에 붙인 `data-label` 이 모바일에서 항목명으로 표시되므로, 행을 추가할 때 `data-label` 을 빠뜨리지 마세요.
- 한국어가 어절 중간에서 끊기지 않도록 `page.css` 의 `body` 에 `word-break: keep-all` 을 두고 있습니다.
