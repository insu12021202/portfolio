04 · 현업 업무 자동화

광고 캠페인
리포트 자동화

1주일
초기 MVP 전체 설계·구현
4시간 → 10분 내
매일 평균 4시간의 수작업을 최초 설정 후 10분 내 다운로드하는 흐름으로 전환
i-flow로 확장
MVP에서 검증한 자동화 흐름을 정식 서비스 기능으로 발전

시간 수치는 사내 기획 문서 기준입니다.

마케터의 반복적인 리포트 작성 업무를 줄이는 채용전환형 인턴 과제로 시작했습니다. 실제 작성 과정을 분석하고, 기존에 수집하던 매체 리포트 데이터와 마케터의 캠페인 정보를 연결해 엑셀 리포트를 생성하는 MVP를 1주일 만에 단독으로 구현했습니다. 연구소장님 리뷰를 거쳐 정식 개발로 이어졌고, 이후 백엔드 개발자와 협업하며 프론트엔드를 담당했습니다. 검증된 자동화 흐름은 이후 i-flow의 캠페인 리포트 기능으로 발전했습니다.

기간 2024.05 – 2025.05 초기 MVP 전체 설계 · 프론트엔드·백엔드 단독 구현 정식 개발 백엔드 개발자와 협업 · 프론트엔드 담당

1 시작 배경과 업무 분석

마케터는 매체별 리포트 데이터를 가져와 회사의 보고서 양식에 옮기고, 캠페인 정보와 수치를 하나씩 확인하고 있었습니다. 이 반복 업무에 쓰는 시간을 줄여보자는 채용전환형 인턴 과제를 맡아, 광고 마케팅 부서를 직접 만나 실제 리포트 작성 과정을 살펴봤습니다.

자동화하려면 데이터를 옮기는 작업뿐 아니라 매체마다 다른 구조와 작성 기준도 이해해야 했습니다. 일반적인 캠페인 → 광고그룹 → 소재 구조 외에 캠페인 → 소재로 구성된 매체도 있었고, 비용 계산 조건과 리포트에 반영하는 기준도 달랐습니다. 이러한 차이를 정리하며 시스템이 처리할 부분과 사용자가 설정해야 할 부분을 구분했습니다.

2 맡은 역할

초기 MVP — 전체 설계와 구현

업무 분석을 바탕으로 자동화 흐름을 설계하고, 프론트엔드와 백엔드를 포함한 MVP를 단독으로 구현했습니다. 기존에 수집하던 매체 리포트 데이터와 마케터의 캠페인 정보를 연결해 엑셀 리포트가 생성되는 최소 흐름까지 직접 만들었습니다.

정식 개발 — 프론트엔드 담당

연구소장님 리뷰를 거쳐 정식 개발이 결정된 뒤에는 백엔드 개발자와 협업했습니다. 캠페인 매칭, 리포트별 설정, 미리보기와 다운로드 등 마케터가 자동화 기능을 사용할 수 있는 프론트엔드를 담당했습니다.

3 핵심 판단과 구현

핵심은 매체 데이터를 엑셀로 내보내는 것만이 아니었습니다. 매체별로 다른 데이터 구조와 리포트 작성 기준을 정리하고, 반복되는 처리는 자동화하면서 캠페인마다 달라지는 조건은 설정할 수 있도록 나눴습니다.

설계 판단내용과 구현
기존 데이터와 캠페인 정보 연결 기존에 수집하던 매체 리포트 데이터를 활용하고, 마케터가 집행한 캠페인 정보와 연결해 리포트를 생성하도록 구성했습니다. 이미 확보된 데이터를 실제 보고서 작성 업무에 활용하는 흐름을 만드는 데 집중했습니다.
매체별 광고 구조 반영 매체마다 캠페인·광고그룹·소재의 구성 단계가 달랐습니다. 각 매체의 구조를 파악하고, 리포트에 필요한 데이터가 해당 캠페인과 연결되도록 반영했습니다.
계산 조건과 보고서 설정 분리 매체별 비용 계산 조건과 리포트 작성 기준을 정리하고, 달라지는 조건을 화면에서 설정할 수 있도록 구성했습니다. 프론트엔드에서는 설정 입력과 검증, 미리보기, 다운로드로 이어지는 사용 흐름을 구현했습니다.

4 MVP에서 정식 서비스까지

  1. 실제 리포트 작성 과정 분석
    마케터가 어떤 데이터를 가져와 어떻게 보고서로 정리하는지 확인했습니다. 매체별 구조와 계산 조건을 정리하고, 자동화할 범위를 구체화했습니다.
  2. 1주일 MVP 구현과 연구소장님 리뷰
    기존에 수집하던 매체 리포트 데이터와 캠페인 정보를 연결해 엑셀 리포트를 생성하는 MVP를 단독으로 구현했습니다. 동작하는 결과물을 연구소장님께 리뷰받고, 정식 개발로 이어갔습니다.
  3. 정식 개발과 사용 기능 확장
    백엔드 개발자가 합류한 뒤 프론트엔드를 담당하며 리포트 설정, 요약 시트, 전체 미리보기와 차트 옵션 등 실제 업무에 필요한 기능을 고도화했습니다.
  4. i-flow 캠페인 리포트 기능으로 발전
    검증한 자동화 흐름은 이후 여러 광고 업무 서비스를 통합한 i-flow의 캠페인 리포트 기능으로 발전했습니다.

시간 수치는 사내 기획 문서 기준이며, 자동화 이후 시간은 최초 설정을 마친 뒤 리포트를 다운로드하기까지의 기준입니다.

7 배운 점

현업의 업무를 충분히 이해하면, 작은 MVP만으로도 무엇을 자동화할 수 있는지 함께 판단할 수 있다는 것을 배웠습니다. 이 프로젝트에서는 매체별로 다른 데이터와 작성 기준을 정리하는 일이 출발점이었고, 이를 실제로 동작하는 흐름으로 구현한 것이 정식 개발로 이어지는 계기가 됐습니다.

이후에도 사용자의 요청과 실제 업무 과정을 함께 살펴보고, 핵심 흐름을 먼저 구현해 관계자와 확인한 뒤 필요한 기능을 발전시키는 방식으로 일하고 있습니다.
