마케터가 매일 평균 4시간을 들이던 광고주 리포트 작성을 자동화했습니다. 현업 인터뷰와 자동화 범위 설계부터 프론트엔드 구현까지 맡아, 최초 설정 후 10분 안에 리포트를 내려받을 수 있는 흐름으로 전환했습니다. 검증된 PoC는 이후 통합 광고 솔루션 i-flow의 캠페인 리포트 기능으로 확장됐습니다.

1 문제

인크로스가 미디어렙을 대행한 광고에 대해, 마케터가 매일 오전 직접 리포트를 만들어 광고주에게 보내고 있었습니다. 매체별 수치 확인 → 템플릿 복사 → 계산 → 시각화를 전부 사람이 처리해 휴먼 에러가 잦았고, 대형 캠페인의 리포트 작성은 밤늦게까지 이어지기도 했습니다. 이상 수치가 나타나면 마케터가 매체 대시보드를 하루 종일 열어두고 감시해야 했습니다.

이 문제를 "불편"이 아니라 리스크로 정의했습니다. 오전 업무 시간이 소모되면서 전략 업무에 쓸 시간이 부족해졌고, 리포트 오류는 광고주 신뢰도 저하로 이어질 수 있었으며, 이상 수치 대응 지연은 광고비 손실 위험을 높였습니다. 담당자의 경험과 스킬에 의존하는 구조여서 품질 편차가 생길 수 있다는 점도 함께 정리했습니다.

2 맡은 역할

이 프로젝트는 현업 인터뷰에서 시작했습니다. 광고 마케팅 부서의 업무 흐름과 예외 케이스를 파악하고, 자동화할 영역과 사용자가 직접 설정할 영역을 구분했습니다. 이를 토대로 인프라·백엔드팀과 협업하고 프론트엔드 설계와 구현을 전담했습니다.

3 핵심 판단과 구현

매체·대행사·캠페인마다 계산 규칙이 달랐습니다. 규칙을 코드에 고정하면 변경할 때마다 수정과 배포가 필요합니다. 계산식·마크업·보정값·분리 조건을 화면에서 설정할 수 있는 데이터로 모델링하고, 프론트엔드에서 입력·검증·미리보기·다운로드 흐름을 구현했습니다.

설계 결정판단 이유와 구현
매체별 소진금액 계산식 설정 매체가 전달하는 소진금액을 그대로 쓸 수 없었습니다(예: Google은 소진금액을 0.7로 나눔). 마크업과 수수료가 매체·대행사마다 달라, 계산식을 화면에서 설정 가능한 값으로 분리했습니다.
DMP 마크업 설정 DMP는 광고 타깃팅에 쓰는 데이터 플랫폼이고, 마크업은 원가에 얹는 가산율입니다. 매체 단위로만 지정하던 마크업을 캠페인·광고그룹 단위까지 확장하고, 매체 마크업과 곱연산하도록 구현했습니다.
보정값·세그먼트·캠페인 분리 보정값은 매체가 전달한 수치를 리포트 기준에 맞추기 위해 더하거나 곱하는 조정치입니다. 리포트마다 다른 산출 방식과, 하나의 캠페인을 여러 리포트로 나누는 경우를 옵션으로 다뤘습니다.
보안 요건 실소진금액(마크업을 얹기 전에 매체로 실제 지급한 금액)이 외부 리포트에 직접 포함되지 않도록, 계산식을 거친 조정값만 전달하는 보안 요건을 반영했습니다.

4 해결 과정

  1. 현업 인터뷰와 업무 흐름 분석
    광고 마케팅 부서를 직접 만나 매일의 리포트 작성 절차와 예외 케이스를 확인했습니다.
  2. 자동화 범위와 설정 영역 설계
    시스템이 자동으로 처리할 영역과 사용자가 직접 설정해야 할 영역의 경계를 정의했습니다.
  3. PoC 구축 및 검증
    설계를 기준으로 인프라·백엔드팀이 합류했고, 빠르게 구축해 실제 업무에서 검증했습니다.
  4. 요약(Summary) 시트 5종·전체 미리보기·차트 옵션 확장
    베타 2차 개발에서 요약 시트 5종과 전체 미리보기, 차트 옵션을 추가했습니다.
  5. 2025년 4월 베타 메뉴 사내 오픈
    템플릿 업로드 검증과 팀·미디어 리스트의 서버 관리 전환을 마치고 메뉴를 열었습니다.
  6. SSO 인증·인가와 광고 모니터링 기능 확장
    SSO 기반 인증·인가를 구현했고, 캠페인별 담당팀 다중 지정과 모바일 앱 푸시 알림을 갖춘 광고 모니터링을 같은 서비스 안에서 확장했습니다.
