팀원마다 달랐던 AI 활용 방식과 개발 절차를 공통 워크플로로 정리했습니다. 요구사항을 함께 검토하는 단계부터 Jira 티켓·GitLab 이슈·작업 브랜치 준비, 커밋·리뷰·MR 작성까지 연결하고 Claude Code 플러그인으로 배포했습니다. 파일럿과 실제 사용에서 받은 피드백을 반영해 작업 범위에 맞는 리뷰 방식을 선택할 수 있도록 개선했습니다.

1 배경과 목표

팀원마다 AI 활용 경험과 개발 절차가 달랐습니다. 작업을 계획하고 이슈를 작성하는 방식부터 브랜치 준비, 리뷰와 기록을 남기는 과정까지 공통으로 활용할 수 있는 흐름이 필요했습니다.

목표는 팀원이 요구사항을 구체화하고 개발을 시작한 뒤, 결과를 검토하고 기록하는 과정을 일관되게 진행할 수 있도록 돕는 것이었습니다. 반복적인 준비와 작성 작업을 스킬로 연결하고, 실제 작업 범위에 맞게 사용할 수 있는 절차를 만들고자 했습니다.

2 맡은 역할

팀 내 AI 활용 TF 리드로서 공통 작업 흐름 정의, 스킬과 훅 구현, 플러그인 배포와 팀 온보딩을 맡았습니다. 기존 업무 흐름과 팀원의 피드백을 확인해 필요한 기능을 구체화하고, 파일럿 적용과 팀 세션을 거쳐 사용 범위를 넓혔습니다.

배포 이후에도 사용 현황과 작업 과정에서 드러나는 요구를 확인하며 워크플로를 개선했습니다.

3 실제 작업 흐름과 검증

요구사항에서 개발 착수까지 연결하는 /start

기존 Jira 티켓이 있으면 요구사항을 읽고 사용자와 함께 작업 계획을 세웁니다. 티켓이 없으면 계획부터 정리한 뒤 공통 작성 가이드에 맞춰 Jira 티켓을 생성합니다.

이후 같은 내용을 개발자 관점의 GitLab 이슈로 구체화하고, 이슈 번호를 바탕으로 작업 브랜치를 생성합니다. 개발을 시작할 준비가 완료되면 /start의 동작이 종료됩니다.

개발 과정의 기록과 커밋

작업별 plan.md와 progress.md를 통해 계획과 진행 내용을 관리합니다. /commit은 팀에서 정한 작성 기준에 맞춰 커밋을 준비하도록 구성했습니다.

작업 범위에 맞춘 /review

작업 범위를 파악해 간단 리뷰 또는 기존의 독립 에이전트 반복 리뷰를 선택할 수 있도록 구성했습니다. 반복 리뷰에서는 네 가지 페르소나의 서브 에이전트가 독립적으로 검토하며, 머지 전에 반드시 해결해야 하는 blocker가 없어질 때까지 리뷰를 반복합니다.

공통 양식으로 작성하는 /mr

리뷰가 완료되면 공통 양식에 맞춰 MR을 작성해, 변경 내용과 검토 결과를 일관된 형식으로 전달하도록 했습니다.

반복 점검을 개발 절차에 연결

타입 검사·자동 포맷·변경 기록과 민감 파일 관련 경고 등을 훅으로 연결했습니다. 훅의 배포 설정과 검사 대상도 검증해, 자동화 절차 자체가 의도대로 동작하는지 확인하도록 했습니다.

스킬 12종과 가드레일 훅 8종을 구성하고, 플러그인 검증 테스트 301건을 구축했습니다. 상시 로드되는 컨텍스트는 103,380자에서 3,779자로 줄여 기본 로드 범위를 정리했습니다.

4 파일럿과 팀 적용

작은 범위에서 먼저 적용

3명·3개 프로젝트에서 파일럿을 진행해 실제 개발 과정에 워크플로를 적용하고 피드백을 확인했습니다.

플러그인으로 배포하고 사용 방법 공유

프로젝트별 설정을 공통 플러그인으로 배포하고, 팀 세션에서 도입 목적과 작업 흐름, 적용 방법을 공유했습니다. 업데이트 시에는 변경 내용과 기존 사용자가 확인할 사항을 함께 안내했습니다.

실제 사용에 맞춰 리뷰 방식 조정

사용 데이터에서 리뷰 없이 머지되는 사례를 발견하고 원인을 확인했습니다. 작은 작업이나 일정상 빠른 확인이 필요한 상황을 반영해, 작업 범위에 맞는 리뷰 방식을 선택할 수 있도록 개선했습니다.

사용 데이터의 수집과 개선 판단 과정은 UX AI Hub에서 자세히 설명합니다.

7 배운 점

공통 워크플로의 기준은 개인의 사용 경험만으로 정하기보다 팀의 실제 업무 흐름과 상황을 확인하며 세워야 한다는 점을 배웠습니다. 같은 리뷰 방식도 작업 범위와 일정에 따라 부담이 달라질 수 있었습니다. 배포 이후에도 사용 데이터와 피드백을 확인하고, 공통 절차를 실제 업무에 맞게 조정하는 과정이 필요했습니다.

이를 지속적으로 확인하기 위해 구축한 측정 플랫폼이 UX AI Hub입니다.
